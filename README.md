# Adisyon SaaS Platform

Kurumsal restoran / kafe / coffee shop / adisyon / POS operasyonlarini yonetecek multi-tenant SaaS platformu.

## Uygulamalar
- `apps/admin-web`: Next.js yonetim paneli
- `apps/pos-web`: React tabanli dokunmatik POS ekrani
- `apps/mobile-manager`: Expo yonetici uygulamasi
- `apps/api`: NestJS backend API

## Paketler
- `packages/ui`: ortak tasarim sistemi bilesenleri
- `packages/types`: ortak domain tipleri ve enumlar
- `packages/config`: environment ve runtime config yardimcilari
- `packages/utils`: yardimci fonksiyonlar

- `docs/01-architecture.md` ile `docs/17-full-version-plan.md` arasinda detayli urun ve teknik cikti seti bulunur.
