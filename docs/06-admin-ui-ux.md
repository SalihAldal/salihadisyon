# 06 Admin UI UX Plan

## Genel Yapý
- Sol sabit koyu sidebar
- Ustte global filtre bar ve hizli aksiyonlar
- Icerikte kart + tablo karmasi
- Her liste ekraninda: arama, filtre, sira, sayfalama, export, detay drawer veya detay sayfasi

## Tasarim Kurallari
- Arka plan: acik gri
- Kartlar: beyaz, yumusak golge, 20px+ radius
- Accent: mor/mavi tonlar
- Kritik durumlar: kirmizi, sari ve yesil durum rozeti

## Tablo Deseni
- Sol kisimda filtre paneli veya top filters
- Orta alanda data table
- Sag tarafta hizli detay paneli veya satir aksiyonlari
- Bulk aksiyon: export, toplu aktif/pasif, toplu etiketleme

## Dashboard Bilesenleri
- KPI kartlari
- Ciro trend chart
- Sube karsilastirma chart
- En cok satan urunler listesi
- Kritik stok alarm listesi
- Gunluk gorev ve mesai paneli
